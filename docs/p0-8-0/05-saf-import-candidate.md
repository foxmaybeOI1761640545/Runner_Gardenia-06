`p0/routes/ui/RouteImportActivity` is an ordinary secondary, nonexported native Activity. It inherits theme/insets and normal Back-to-caller behavior. It is intentionally not linked from Home/Settings until the route library phase D. It adds no fifth root and does not change P071 navigation. English/Chinese resources, scrolling content, 48dp actions and accessible state announcements use the existing theme system.

OpenDocument requests `*/*`; GPX content decides acceptance regardless of extension/MIME. ContentResolver streams are read on a serial worker, never converted into real paths or retained as a long-lived dependency. Display-name query failure is nonfatal; missing stream, revoked access, malformed GPX, invalid candidates, empty/waypoint-only documents and read interruption are explicit. Source byte/point/metadata limits remain those of the accepted parser. No original GPX copy is persisted.

A rotation-retained AndroidViewModel owns reading, byte progress, valid/invalid multi-route preview, selected valid candidate ordinals and duplicate-source matches. No candidate is automatically selected or silently merged/dropped. Invalid candidates remain visibly disabled with reasons. The route repository is untouched until explicit selected import; duplicate sources require explicit additional-copy confirmation. Existing UUIDs are never overwritten. Import success follows both repository commit and independent selected-route reopen/equality checks. Repeated clicks cannot submit a second commit.

Cancellation while reading invalidates late callbacks, interrupts the task and closes the provider stream on a separate closer so provider close cannot block the UI. It writes no formal routes. Back during a short formal commit is held until its atomic result, preventing an ambiguous user cancellation after commit. Process recreation before a confirmed import requires reselection; it does not secretly replay a content URI or an import. Persisted route transactions remain recoverable by the phase-B mechanism. The Activity returns saved UUIDs to its caller; its Done action returns normally.

All production document/repository I/O stays off the main thread. No location permission, GPS owner, service start/bind, history write, BLE configuration, recording state or SQLite schema change is present in these UI classes. The existing application-wide foreground policy remains unchanged.

The new test-only provider is declared through an androidTestReproducible manifest overlay, preserving the old test manifest and every predecessor Java test byte. It supplies nonseekable pipes, a deliberately nonstandard MIME, partial valid/invalid data, missing names, slow streams, read failures and malformed/empty/waypoint-only files. Ten API35 cases test actual SAF result handling/streaming, selected multi-route import, invalid selection rejection, explicit duplicate copies, rotation, picker cancellation/exception, streaming cancellation, errors and double-submit prevention.
