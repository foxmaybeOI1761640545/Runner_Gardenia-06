# 设计规范与十套方案

这是独立设计实验室，HTML 原型不是 Android 正式 UI。十套方案共用同一份页面内容与状态，不增添训练计划、云同步、评分、社交、在线地图等未实现的 P0 功能。

## 设计方向与布局差异

| # | 方案 | 运动页的结构差异 | 全局组件语言 |
|---|---|---|---|
| 01 | Precision Pro | 距离主读数 + 精密分割的 2×2 指标网格 | 石墨底、荧光绿、细线、仪表感 |
| 02 | Quiet Minimal | 中轴距离、细字重、开放留白、卡片退化为分隔线 | 白底、克制导航、卡片去边框 |
| 03 | Outdoor Explorer | 260px 地形概览优先，距离叠于图上，紧凑三列指标 | 森林绿、土地色、手记式标签、方形状态 |
| 04 | Neon Pulse | BPM 与心率波形先行，距离仍以显著指标保留 | 暗紫底、青色曲线、霓虹描边、双层指标卡 |
| 05 | Swiss Editorial | 纵向章节标记 + 非对称大数字、杂志式横线 | 米白、红黑、硬线与无圆角 |
| 06 | Industrial Gauge | 环形机械刻度包围距离，等宽数字窗 | 琥珀、深灰、3px 小圆角、机械面板 |
| 07 | Calm Wellness | 有机圆环 + 柔和居中读数、独立软指标 | 奶油白、薄荷、25px 软卡片和胶囊按钮 |
| 08 | Aurora Glass | 渐变玻璃主卡 + 层叠半透明指标，数字优先 | 蓝紫、透明描边、实色足够的内容层；无模糊 |
| 09 | Racing Performance | 倾斜大型记分板读数、裁角黑色面板、紧密分区 | 黑白红、速度条纹、加粗斜体数字 |
| 10 | Data Brutalism | 黄色主数据块、硬边 2×2 几何指标 | 黑白黄、2–3px 线、偏移硬阴影、等宽字体 |

以上不仅更换颜色：`app.js` 的 hero renderer 选择不同 DOM 组合，`styles.css` 为所有页面的卡片、列表、标题、按钮和导航定义主题结构规则。四个主导航、历史详情、图表、GPS 与导出内容仍完全一致。

## 信息优先级

1. 运动页：GPS/BLE 状态 → 当前记录状态 → 距离/时长/心率 → 主要记录操作 → 定位解释/路线 → 最近运动。
2. 未定位时：未知值 `--`、精度尚未确定、等待有效定位，不绘制当前轨迹或经纬度。
3. 心率页：当前有效 BPM / 更新时间 / 接触 → 所选设备、ID、RSSI → 手动重连 → 主动断开 → 自动重连 → 曲线。
4. 历史：总览 → 日期有序列表 → 详情含 min/avg/max 与轨迹/曲线 → GPX。
5. 设置只整理已有偏好、离线与隐私说明，不添加业务能力。

## 共享视觉参数

手机内容设计基准 393×873，屏幕保持固定比例，外壳 413×893。桌面根据高度和可用列宽用等比 transform 缩放，移动端以宽度和可用高度共同约束；应用内部滚动与网站外部滚动分开。系统状态栏、前置摄像头、导航安全区属于模拟器呈现。

参数表、完整十主题色板、sp/dp 迁移策略、字号、间距、圆角、阴影、图标、图表、操作规范见 [原生实现指南](NATIVE_UI_IMPLEMENTATION_GUIDE.md)。原型 CSS 小字号用于缩放展示，正式原生应使用指南中的可访问字号。

## 状态与交互

- GPS 与 session 为独立维度：GPS 丢失不会自动变成“用户暂停”；搜星时不能从空闲开始有效记录；暂停恢复需要有效定位。
- 模拟计时按前台 tick 增加；有效定位时才递增距离，丢失或页面隐藏时不做补算。所有展示均明确为模拟。
- 新鲜 BPM 需 connected + contact。未连接、连接中、重连、过期或接触不良均 `--`；手动重连先清空旧 BPM，再模拟收到新数据。
- 自动重连开关不会承诺或强制成功；真实 BLE 问题仍需硬件验证。
- 切换设计保留 current page、详情、单位、记录、设备与导出状态；仅刷新视觉。默认 8 秒自动轮播，操作后持续暂停，点击播放恢复。悬停、聚焦、隐藏页面、打开模态框暂停；减少动态效果默认关闭自动轮播。
- 所有主题可通过按钮、页码、方向键、触摸横扫选择；鼠标拖动滚动缩略卡。鼠标拖动不意外选择卡片。
- 导出弹窗锁定应用内部背景焦点，Tab 循环、Escape 关闭、关闭后恢复触发按钮。保存产生有效的本地 GPX 示例下载；系统文件分享可用时调用分享，否则下载。仅生成含 SIMULATION 标记的合成数据。
- 收藏仅作为方案比较工具，以 localStorage 保留主题 ID，不保存运动或设备数据；浏览器禁用存储时本次会话仍可使用。
