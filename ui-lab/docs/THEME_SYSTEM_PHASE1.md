## Canonical tokens

`assets/design-tokens.json` schema v2 contains `id`, `name`, `defaultAppearance`, complete `light` and `dark` semantic palettes, `shapeTokens`, `typographyTokens`, `chartTokens`, mode-specific `componentTokens`, and `nativeImplementation` metadata. Both palettes have background, surface, surfaceVariant, foreground, foregroundSecondary, accent, accentForeground, tint, divider, outline, success, warning, danger, chartColors and statusColors. Compatibility `cssTokens` describe the default appearance.

`tests/generate_palettes.py` produces local CSS and JS resources; no fetch, external font, map, or device API is added. CI verifies generated bytes against JSON. Fluorescent accents remain fills with a separate readable accentText for body labels/charts. All body, secondary, status and button token pairs are checked to WCAG AA 4.5:1 or better. Shape, weights, numeric style, native metadata and chart gap policy remain theme-owned.

## Interaction

Light and Dark explicitly override browser preference. System Preview subscribes to the real `prefers-color-scheme` media query. The ten-card selector retains numbering and names, adds a resolved mode and keyboard-accessible Light/Dark buttons. The synchronized comparison shows the current page and simulation state in both palettes; each pane scrolls independently. Main controls own actions, preventing duplicate simulations or GPX exports. Two columns collapse to one on phones. Palette changes update semantic CSS attributes without reinitializing recording/GPS/BLE state, metrics, navigation or dialogs.

The ten original hero renderers and original layout stylesheet are retained. Precision grid, Quiet open layout, Explorer terrain, Neon heart-first waveform, Swiss editorial rules, Industrial gauge, Wellness ring, Aurora glass, Racing scoreboard and Brutal blocks remain distinct.

The gate receipt will record exact source commits, Actions run, counts and evidence hashes. A green deploy step alone does not open this gate.

## Local browser environment note

The first complete regression reached the final direct-file offline test and failed with `ERR_BLOCKED_BY_ADMINISTRATOR`: the environment's shared Chromium has a managed URL allowlist that excludes `file://`. Its raw failure JSON is retained in `docs/acceptance/theme-system/local-managed-browser-failure.json`. No managed policy was changed. An official Playwright Chrome for Testing was installed into the task's intermediate tooling directory; a network-disabled direct-file probe loaded all four navigation buttons, and the full regression is rerun with this browser. This environment failure is not treated as a successful regression, and no assertion is skipped. The independent appearance matrix continues to use the environment's real Chromium through HTTP.

Report-only changes under `docs/acceptance/` and `docs/THEME_SYSTEM_DELIVERY.md` do not trigger another Pages build. The delivery report explicitly distinguishes the tested/deployed source SHA from a subsequent evidence-only branch HEAD.

## Component-level visual regression guards

Reviewing the complete heart/history/settings screenshot sheets exposed three inherited component fill overrides that token-only checks could not detect: Quiet history summary, Aurora Dark history summary, and Brutal Dark selected-device ink. Explicit semantic ink/fill mapping fixes these without changing geometry. Browser acceptance now computes final composited foreground/background contrast on the history summary and every selected-device text field for all 20 palettes and three viewports. The superseded first cloud candidate was canceled before deployment; its run remains visible.
